Install on this computer

Each installer adds a desktop shortcut that opens the right portal. Workers need only the Worker installer.

Windows desktop app (recommended)

Its own window, a tray icon, and notifications when a standup update or meeting is due. For workers and admins on Windows 10 or 11.

  1. Download the zip below, right-click it and choose Extract All.
  2. Double-click Install-Desktop-Windows.bat in the extracted folder.
  3. If Windows says "Windows protected your PC", choose More info, then Run anyway.

    Seeing "Not secure" in your browser?

    This server uses its own certificate. Each computer that uses the app in a browser trusts it once. (Not needed for the desktop app.)

    1. Windows: download Trust-Certificate-Windows.bat, double-click it, and choose Yes at the security warning. No administrator rights needed.
    2. Close all browser windows, then open the app again.
